- Read the approved plan in full, then the repo's AGENTS.md (its hard rules hold). Title the session as its brief says; tag `project:<short name in lower case>` and `fleet-v2`.
- Kit 11.0.0 is not merged yet. Do the project-local work now. Do NOT sync the kit until the coordinator says kit 11.0.0 is on main; that sync is a separate, later PR. Role words ("the Administrator", "the PFM", "the PAM", "the owner" -> "the Maintainer") arrive by that sync: never hand-edit them.
- Re-check every cited file:line before you edit it (the plan's source text had wrong lines). Edit a generator's source and rebuild; never edit a generated file.
- Gates: report the exit code and the test count (> 0) of each gate, before and after. Contrast: compute WCAG ratios in code (a test), never by hand.
- Deliver (DEC 10): branch `claude/fleet-v2-<topic>`, PR, full `scripts/check.sh` green, a fresh `reviewer` subagent on the head commit with no MAJOR finding, then merge with a merge commit. Stop on a MAJOR finding, a red gate, drift from the plan, or an invariant failure (DEC 12).
- Invariants: (a) live rhope-ops / RHOPE-OPS values stay active, in the repo's one config file; (b) 0 DoD security items in ICF-Source; (c) icf pagecount.mjs Cloudflare analytics stays active; (d) the accessibility `!important` rules (reduced motion, [hidden], .sr-only) stay; (e) no generator re-injects `-ExecutionPolicy Bypass`.
- No real names or email addresses anywhere (roles only). Record decisions in docs/DECISIONS.md and status in docs/NEXT_PROMPT.md.
- When done: send_message to the coordinator with the PR links, the gates (exit codes, counts) and the invariant results.
