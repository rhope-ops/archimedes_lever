# Kit changelog

One line for each kit version that a project must take by a sync (`scripts/sync_baseline.py`, run from the project). The version (`KIT_VERSION`, since 1.0.0 a semantic version with a git tag `v<version>`) says how much work a sync is: MAJOR when a project must do more than run the sync (a migration, a moved file, a changed kit rule text), MINOR for new behavior that the sync alone brings, PATCH for a fix. Versions before 1.0.0 were dates. A project's `.check.lock` records the version and the commit it has. Why each change was made: [DECISIONS.md](DECISIONS.md).
