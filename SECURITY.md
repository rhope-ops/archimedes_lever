# Security policy

## Report a vulnerability

Do not open a public issue for a security problem. Use private reporting on GitHub.

1. On GitHub, open the main page of this repository. You see the row of tabs. Go on.
2. Click the tab **Security**. You see the page **Security overview**. Go on.
3. Click **Report a vulnerability**. You see the form **Report a vulnerability**. Go on.
4. In the form, type a title. Describe the problem, the files it touches and the steps that show it. You see your text in the form. Go on.
5. Click **Submit report**. You see your report in the list. The task is complete.

Write no secret, token or personal data in the report.

## What happens next

The Maintainer reads each report and answers in the report. The Maintainer tells you if the problem is real and which version has the fix. The Maintainer does not publish the report until a fix is available.

## Scope

This policy covers the scripts, hooks and workflows in this repository. The file docs/threat-model.md lists the assets and the known risks.
